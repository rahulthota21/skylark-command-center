## Before submitting to Skylark

1. [ ] Import boards using `IMPORT_TO_MONDAY.md`.
2. [ ] Deploy using `RUN_AND_DEPLOY.md`.
3. [ ] Test in an incognito window.
4. [ ] Put the public Vercel URL at the top of `README.md`.
5. [ ] Download/source-upload `Skylark-Command-Center-Submission.zip` or share your GitHub repository URL.
6. [ ] Submit public app URL, source ZIP/repo URL, README, and Decision Log in the form.
7. [ ] Optional but recommended: include a 60–90 second Loom using `DEMO_SCRIPT.md`.
